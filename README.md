# 광명시 공시지가 대시보드

광명시 개별공시지가(2025→2026) 실습용 데이터 402건을 법정동 경계 지도·차트로 보고,
PNU 형식·중복·결측값·변동률 이상치를 자동 검증하는 단일 HTML 대시보드입니다.

## 파일

- `index.html` — 대시보드 본체 (정적 HTML/CSS/JS, 빌드 과정 없음). 같은 폴더의 `data.csv`를 fetch로 불러옵니다.
- `data.csv` — 원본 데이터 (연번, PNU, 소재지, 법정동, 지번, 지목, 면적, 용도지역, 공시지가_2025/2026).
- `build-geo.js` / `dong-geo.json` — 법정동 경계 지도 좌표를 생성한 스크립트와 그 결과물.
  국가통계포털(vuski/admdongkor, 2023-07) 행정동 경계를 법정동 단위로 병합·투영해서 만들었습니다.
  `index.html`에는 이 결과가 이미 인라인으로 포함되어 있어 재생성하지 않아도 됩니다.

## 보기

`index.html`을 더블클릭하면 안 됩니다 (fetch가 `file://`에서 막힘). 로컬 서버로 띄워서 보세요:

```bash
npx serve .
# 또는
python -m http.server 8080
```

## 지도 관련 참고

노온사동·가학동은 행정동 경계가 '학온동' 하나로만 공개되어 있어 지도에서는 한 구역으로 표시됩니다.
차트·표·검증 결과는 두 법정동을 구분해서 집계합니다.
